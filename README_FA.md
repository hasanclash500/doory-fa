# دوری فارسی — Doory FA

پروژهٔ شخصی فارسی‌سازی و بسته‌بندی اندروید برای Doory 0.2.0.

## وضعیت توسعه

- سورس اصلی از نسخهٔ رسمی `v0.2.0` مخزن `shaongitbd/doory` وارد شده است.
- رابط کاربری راست‌به‌چپ است، ۳۶۳ عبارت متداول فارسی شده‌اند، و متن‌های داخل طرح کاربران از ترجمهٔ خودکار مستثنا هستند.
- متن‌ها و پیام‌های پویا در برخی صفحه‌ها ممکن است هنوز انگلیسی باشند؛ این نسخه **فارسی‌سازی کامل و بازبینی‌شدهٔ تمامی صفحات نیست**.
- انتشار نسخهٔ آزمایشی اندروید با GitHub Actions انجام می‌شود.
- بک‌اند Django داخل APK بسته‌بندی نمی‌شود. برای ورود، ذخیرهٔ ابری، همگام‌سازی و قابلیت‌های سروری به استقرار HTTPS این سرویس نیاز است.

## نصب APK آزمایشی با گوشی

پس از موفقیت [گردش‌کار ساخت APK](https://github.com/hasanclash500/doory-fa/actions/workflows/android-apk-fa.yml)، اجرای موفق را باز کنید و بستهٔ `doory-fa-debug-apk` را از قسمت **Artifacts** دانلود کنید. ZIP را روی گوشی استخراج کنید و فایل `app-debug.apk` را نصب کنید. نصب از منابع ناشناس ممکن است نیاز به اجازهٔ صریح اندروید داشته باشد.

APK به صورت پیش‌فرض نمای وب را از بستهٔ محلی اجرا می‌کند؛ بنابراین قابلیت‌های سروری بدون استقرار بک‌اند فعال نمی‌شوند.

## نسخهٔ متصل به سرور

1. پروژهٔ Doory را همراه Django/PostgreSQL مطابق [راهنمای رسمی](https://github.com/shaongitbd/doory/blob/main/docs/self-hosting/docker.md) روی یک دامنهٔ HTTPS مستقر کنید.
2. در GitHub مخزن خودتان، از مسیر `Settings → Secrets and variables → Actions → Variables` متغیر `DOORY_APP_URL` را با آدرس HTTPS همان نصب تنظیم کنید.
3. گردش‌کار ساخت APK را دوباره از بخش Actions به صورت دستی اجرا کنید.

در حالت سرور متصل، صفحات نسخهٔ مستقر نمایش داده می‌شوند؛ بنابراین **برای حفظ رابط فارسی باید نسخهٔ فارسی همین مخزن روی سرور مستقر باشد**.

## مشارکت در ترجمه

واژه‌نامه در `frontend/src/i18n/fa-dictionary.ts` قرار دارد و منطق محلی‌سازی در `frontend/src/i18n/fa.ts` است. رابط کاربری مستقل از محتوای داخل بوم طراحی ترجمه می‌شود.

## حقوق سازنده

پروژه بر پایهٔ [Doory](https://github.com/shaongitbd/doory) اثر Siam و مشارکت‌کنندگان ساخته شده است. انتساب و مفاد مجوز اصلی در فایل‌های `LICENSE`، `NOTICE` و `AUTHORS.md` حفظ می‌شوند. این مخزن وابسته به سازندهٔ اصلی نیست.
